## 10.1 V1 → V2 升级清单

> V2 功能均来自 [01-overview.md](./01-overview.md) §1.5「不做清单」+ MRD P1/P2 推迟项。

| 功能 | 优先级 | 前置依赖 | 预估复杂度 | 备注 |
|------|-------|---------|-----------|------|
| **手动 bot 验证付费假设**（先于 V1 上线）| P0 | 无 | 低 | [BRD.md](../BRD.md) §3 强制项：写代码前先用 Telegram/Line bot 找 30-50 名 TikTok 倾诉用户验证打赏意愿。**通过后才动 V1**，未通过则改商业模式 |

| 多种牌阵（三牌：过去/现在/未来）| P2 | V1 用户对单牌的复购数据 | 中 | MRD P2 信号弱，但拓展仪式感 |
| 78 张完整塔罗牌 | P2 | V2 牌阵功能 | 中 | 需要美术资源 + prompt 优化 |
| 用户自选喜欢的算命师 IP（人设）| P2 | 需要内容侧多人设语料 | 高 | 借鉴 Replika 多 persona 思路 |
| 真人算命师入驻 / 抽成模式 | P3 | V2 留存 + 付费率达标 | 高 | BRD 替代商业模式 |
| 移动端 PWA（添加到主屏幕）| P2 | V1 验证回访率高 | 低 | 不做原生 App |
| 多语言切换（中文/英文）| P3 | 跨平台代表性验证 | 中 | BRD 假设 4 验证后再扩 |
| 历史记录（可选开启）| P3 | 与匿名性的 trade-off | 中 | 需谨慎设计——可能违背产品价值根基 |
| 危机干预升级到 AI 辅助识别 | P2 | V1 关键词命中率数据 + 法律审查 | 高 | V1 仅用关键词词典；AI 识别误报代价大 |
| 音频播报开示（语音版）| P3 | V1 文字版稳定 | 中 | 凌晨场景下听比读更亲密 |

## 10.2 长期方向

借**占卜壳子**做泰国情绪陪伴产品的目标不是"让 AI 替代心理咨询"，而是**降低心理求助的文化门槛**——让"看一张牌"成为更多扛家者第一次承认自己累了的入口。

12 个月愿景：从单次抽牌打赏，演化为"凌晨深夜里有一盏小灯"的轻品牌——可以延伸到其他东南亚泰语圈、其他被忽视的"扛家者"群体（中年男性、长期照护者等）；也可能反向输出泰语开示语料，成为东南亚情绪 AI 内容的语料标杆。

但这一切的前提是：**V1 的付费假设跑通**。BRD §3 已说明这是 🔴 低置信度假设，本 roadmap 的所有 V2+ 功能都是"假设跑通后"的规划，不是必然。

## 10.3 已知技术债

| 技术债 | 影响范围 | 建议解决时机 |
|-------|---------|------------|
| 危机关键词词典是硬编码起步版本 | 误报/漏报风险 | V1 上线前由本地内容顾问扩充至 ≥ 30 个核心词；V2 评估 AI 辅助识别 |
| 牌组仅 22 张大阿尔卡那 | 用户重复抽到同一张概率较高 | V2 扩到 78 张全套（需要美术资源） |
| `sessions.confess_text` 24h 后置 NULL 依赖 cron | cron 故障会导致隐私承诺失效 | V1 上线前测试 cron 可靠性；V2 考虑入库时即加密，cron 仅删 key |
| 流式中断后的恢复逻辑简单（重新生成新开示）| 用户在断网后会丢失上一段开示 | V2 引入服务端 SSE 重连机制 |
| 仅支持 PromptPay 一种支付方式 | 无银行 App 的用户无法打赏 | V2 增加信用卡 / TrueMoney（非急迫，目标用户大多有银行 App） |
| Supabase 免费额度限制 | 流量增长后需要升级付费 | 监控用量，达到 80% 时考虑升级或自建 PG |
| 没有 e2e 测试 | 关键流程（抽牌→倾诉→开示→打赏）依赖手测 | V1 上线后补 Playwright 覆盖核心流程 |
| 内容审核双层但无人工复核循环 | 长期运营会积累误判案例 | V2 加内部审核台账 + 周度复盘机制 |
| 价格 / 金额档位是硬编码常量 | A/B 测不同价格需要发版 | V2 抽到环境变量或后台配置 |
| 没有正式的运营后台 | 数据查看依赖 Supabase Dashboard | V2 简单后台（只读统计 + 危机日志查看）|

## 10.4 不做（永久 / 长期）

- ❌ 让 AI 处理用户的危机干预（专业度 + 法律风险，永远转给真人热线）
- ❌ 强制注册 / 实名（违背匿名 P0 价值）
- ❌ 显示其他用户的真实倾诉原文（隐私）
- ❌ 通过开示植入广告 / 引导其他平台
- ❌ AI 模拟具体真人算命师（伦理 + 版权风险）
